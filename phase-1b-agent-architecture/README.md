# Phase 1B — Agent architecture

The authoritative design is [Agent architecture and deal flow](agent-architecture-and-deal-flow.md). It specifies six specialist responsibilities and one Orchestrator, starting with a structured deal and ending in an evidence-backed recommendation for **human** approval. Credit and Policy remain independent for domain-specific results and error attribution. Hard calculations, constraints and required approval roles are validated by rules.

The 11 October design adds bounded options for configuration, price, delivery, credit evidence and policy correction. The Orchestrator compares proposed options, reruns affected checks and preserves the original submission. These capabilities are **planned**, not implemented by the current Phase 1C rule gate. First test one shortage → partial delivery or substitute → full recheck case using the existing schema and a typed candidate record; decide candidate persistence from the trace test before considering a schema migration.

The [workflow image](assets/six-agent-workflow.png) illustrates the **initial assessment path**. It does not depict the new bounded alternative-and-recheck loop; the written specification governs the full flow. Phase 1A remains separate. Phase 1C's [data strategy](../phase-1c-data/design/data-strategy.md#19-structured-input-recommendation-extension--11-october-2026-target-design) maps these roles and options to data, and its [README](../phase-1c-data/README.md) reports current implementation status.
