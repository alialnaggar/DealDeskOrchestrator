## Demonstrated review-package defect and bounded correction

The first strengthened six-stage assertions failed **before the fix**: in the no-candidate path `run_original_investigate_and_review` saw a nonempty *partial* Pricing reviewer projection and skipped constructing the original summary. In the candidate path `_package` rebuilt the fixed candidate review without retaining the already validated typed Pricing projection. Configuration's validated original result was stored in `m20_ai_results` but not surfaced next to these projections. The test's initial exploratory command also had an incorrect unittest class selector and a new local test-variable shadowing the disposable checkpoint name; those *test* errors were corrected and are not runtime/provider failures. No validator was weakened.

The narrow fix: `investigation_graph.py` finishes a no-candidate original review when the only prior field is the typed Pricing projection; `candidate_graph.py` preserves that projection **only when it matches the saved typed result and original source/subject**, and adds a bounded original Configuration projection **only when its saved result identity matches**. `m21_specialists.py::checked_candidate_context` checks both projections on the candidate path. The offline test rejects tampered candidate-subject Pricing and altered Configuration review claims. The final package now has original fixed findings, separately fixed candidate findings if present, Configuration and Pricing original projections, Fulfillment original contribution and Credit/Policy/Routing original projections with fixed route/authority. These fields are **AI observations**, not business authorization. No candidate fixed check, model send, rule calculation or Phase 1C reader was changed.

**Example:** On N01/UC02, no partial delivery is allowed; Credit's selected Review profile is stale and no AR/payment was returned. The offline Credit double abstains while fixed Credit remains `unknown`. The no-candidate package now includes the original six fixed summaries, the original Configuration/Pricing AI projections, the M2.1 Credit/Policy/Routing review and a human-only action. A completed restart does not send again. This does not establish a complete zero balance, hosted abstention, clearance or approval.
