## Source-only semantic review of the validated live payloads

After the runs, compare their validated free-text claims with the prewritten answer sheet and the pinned R03 reference rows. The fixture requests **20 by 10 September 2026**, forbids partial delivery, has an uncommitted supplier offer and no binding inbound receipt. Both Groq answers correctly described the offer as conditional and cited a returned authorized record. Both also wrote an unqualified form of **“No confirmed supply is available”**. This can sound like a claim about all possible supply, while these tools expose a bounded selected reader pool. Trial 2 additionally speculated that the sealed pool might contain inaccessible records; this is not established by the returned sources.

**Assessment:** 2/2 live eligible outputs passed structural and returned-citation checks, but **0/2 pass strict semantic scope review as written**. Record two unsupported absolute-absence statements as critical *semantic qualification* failures; trial 2 has an additional unsupported speculation. These are **not** fabricated positive commitments: 0 invented confirmed supplier receipts, 0 invalid returned-source citations, 0 authorization violations, 0 approvals or changed fixed results were observed. Counts apply only to these two repeated trials of R03, not to diverse cases or Gemini. The source-only review is independent of model-generation input, but no separate human reviewer has accepted it as thesis ground truth.

## Bounded hardening and remaining limits

The prompt now explicitly requires availability/absence claims to be limited to returned records in the pinned selected reader pool, forbids speculation about inaccessible sealed records and permits abstention when evidence is insufficient. Its version is `m15-fulfillment-v1`; offline tests assert these instructions are present. This is a communication guard, **not** a deterministic semantic verifier. The added runtime requirement for returned citations and nonblank finding text rejects one previously permitted unsupported-output class. A correctly cited sentence can still be semantically false or overbroad; keep source-only human review as a required evaluation gate. Do not replace Phase 1C's fixed feasibility, quantities, dates or candidate verification with keyword filtering or model confidence.

The illustrative 20/12/8 split is still synthetic offline and **unverified**. Mixed binding/conditional candidate verification requires Phase 1C-owned compatible fixed support. Only one pinned real reference currently demonstrates eligibility for live Fulfillment AI; the other reference checks mainly exercise fixed rules and safe gating. The new prompt's effect has not been measured live; no claim of semantic improvement follows from its addition. Retain Groq as provisional development provider and Gemini as optional later comparison. M1.6 requires separate approval and a plan addressing semantic claim review and the Phase 1C conditional verifier dependency.
